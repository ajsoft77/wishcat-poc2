# 파츠핏 (가칭) — 자동차 부품 쇼핑몰 시안

카페24 기반 자동차 부품몰 제안용 작동 시안. 서버 없이 브라우저만으로 동작하며,
상품·품번·가격·차량 제원은 모두 시연용 예시 데이터다.

관리자 화면은 주소 끝에 `#/admin` 을 붙여 연다.

## 들어 있는 것

| 구분 | 화면 | 내용 |
|---|---|---|
| 쇼핑몰 | 홈 | 차량 검색 위젯(차량번호 / 차종 단계 선택 / 차대번호), 조회된 제원 표시 |
| | 목록 | "내 차에 맞는 부품만" 필터, 상품별 호환 배지, 품번 교차 검색 |
| | 상세 | 호환 여부 안내, 호환 차종 표, 순정 품번·대체 부품 |
| | 장바구니·주문 | 비호환 경고, 주문서 차량번호/차대번호 입력란 |
| 관리자 | 차종 마스터 | 제조사 › 모델 › 세부 트림 추가·수정·삭제 |
| | 부품-차종 매핑 | 부품 검색 후 차종 트리 체크박스로 연결 (즉시 쇼핑몰 반영) |
| | 차량조회 캐시 | 재조회 시 외부 API 미호출, 조회 기록·절감 추정 |
| | 시스템 구성 | 카페24 + 중계 서버 구성도 |

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 호환 검색·교차 검색·캐시 로직 테스트
npm run build    # dist/ 생성
```

## 구조

- `src/data/vehicles.ts` 차종 마스터 예시, `src/data/parts.ts` 부품·호환 그룹 예시(약 460개 상품)
- `src/lib/fit.ts` 호환 색인·품번 교차 검색 (순수 함수)
- `src/lib/relay.ts` 중계 서버 역할 흉내 (외부 차량 API 대체 응답 + 캐시)
- `src/store.ts` 상태 + localStorage (`partsfit-demo`)
- `src/pages/` 쇼핑몰 4개 화면 + 관리자, `src/components/` 공통 UI
- `public/img/*.jpg` 부품 이미지 10종. 직접 만든 3D 모델을 렌더링한 것 (`node scripts/render/run.cjs` 로 다시 생성, 외부 사진·브랜드 로고 없음)

## 배포

`dist/` 는 정적 파일이라 어떤 호스팅에도 올릴 수 있다. 상대 경로로 빌드하므로 하위 경로(`/parts/` 등)에 올려도 동작한다.
`scripts/serve.py <포트>` 는 `dist/` 를 서빙하는 간단한 정적 서버다.

## 시안과 실제 구축의 차이

- 차량번호 조회 결과는 가상 데이터다. 실제로는 중계 서버가 외부 차량정보 API를 호출한다.
- 상품은 카페24 상품이 아니라 내장 예시다. 실제로는 카페24 상품번호로 연결한다.
- 상품 이미지는 카테고리별 3D 렌더링 1장씩이다. 실제로는 상품별 사진을 쓴다.
- 관리자 수정 내용은 이 브라우저에만 저장된다.
